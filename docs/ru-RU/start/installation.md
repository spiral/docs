# Начало работы — Установка

Spiral предоставляет удобный установщик приложений, который позволяет разработчикам легко устанавливать и настраивать фреймворк и любые желаемые пакеты через интерфейс командной строки. Это помогает упростить процесс начала работы с Spiral и упрощает настройку среды разработки.

Он может быть очень полезен для установки всех необходимых конфигурационных файлов, переменных окружения и загрузчиков (Bootloader) для желаемых пакетов и компонентов. Установщик позволяет разработчикам легко устанавливать различные пакеты и компоненты, включая:

- [Cycle bridge](../basics/orm.md)
- [Валидаторы](../validation/factory.md)
- [Event Dispatcher](../advanced/events.md)
- [RoadRunner Bridge](../start/server.md)
- [Temporal Bridge](../temporal/configuration.md)
- [Планировщик cron-задач](../advanced/scheduler.md)
- [Sentry bridge](../basics/errors.md)
- Движок шаблонов [Stempler](../views/stempler.md) или [Twig](../views/twig.md)
- [Сериализатор](../advanced/serializer.md)
- [Компонент почты](../advanced/sendit.md)
- [Метрики RoadRunner](../advanced/prometheus-metrics.md)

Наличие этих пакетов и компонентов, легко доступных и правильно настроенных через установщик, может сэкономить разработчикам время и усилия при настройке среды разработки и запуске их проектов.

## Требования к серверу

Убедитесь, что ваш сервер настроен со следующей версией PHP и расширениями:

* PHP 8.1+, 64bit
* расширение *mb-string* (spiral — это UTF-8-ориентированный фреймворк)
* расширение *socket*
* расширение *curl*
* расширение *zip*

## Установка

Процесс установки с установщиком очень прост и удобен в использовании. Вы можете использовать следующую команду для создания нового проекта:

```terminal
composer create-project spiral/app my-app
```

И вы увидите следующий вывод:

```output
[32mCreating a "spiral/app" project at "./my-app"[39m
[32mInstalling spiral/app (1.1.1)[39m
  - Installing [32mspiral/app[39m ([33m1.1.1[39m): Extracting archive
[32mCreated project in /var/www/my-app[39m
> Installer\Installer::install

  [30;46mWhich application preset do you want to install?[39;49m
  [[33m1[39m] Web
  [[33m2[39m] Cli
  [[33m3[39m] gRPC
  Make your selection [33m(1)[39m:
```

> **Примечание**
> Когда что-то пошло не так во время процесса установки, вы всегда можете перезапустить его, выполнив команду `composer install`.

После установки приложения в корневом каталоге проекта будет создан файл `README.md` с инструкциями о том, как запустить сервер приложений и как запустить приложение.

> **Внимание**
> Сервер приложений RoadRunner будет загружен автоматически. Требуются `php-curl` и `php-zip`.

## Запуск сервера

Для запуска сервера приложений выполните:

:::: tabs

::: tab Linux

Используйте следующую команду для запуска сервера RoadRunner на **Linux**

```terminal
./rr serve
```

> **Внимание**
> Убедитесь, что бинарный файл `rr` является исполняемым.

:::

::: tab Windows
Используйте следующую команду для запуска сервера RoadRunner на **Windows**

```terminal
.\rr.exe serve
```

:::

::::

По умолчанию приложение будет доступно по адресу `http://localhost:8080`.

> **Узнать больше**
> Читайте больше о сервере приложений в разделе [Начало работы — Сервер приложений](../start/server.md).
