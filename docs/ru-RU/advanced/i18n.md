# Компонент — Интернационализация

Компонент интернационализации Spiral основан на пакете `symfony/translator` и предоставляет совместимые интерфейсы. Веб-пакет включает это расширение по умолчанию.

## Установка

Чтобы включить расширение в альтернативных сборках:

```terminal
composer require spiral/translator
```

Зарегистрируйте загрузчик (bootloader) `I18nBootloader` в вашем приложении.

:::: tabs

::: tab Использование метода

```php app/src/Application/Kernel.php
public function defineBootloaders(): array
{
    return [
        // ...
        \Spiral\Bootloader\I18nBootloader::class,
        // ...
    ];
}
```

Читайте больше о загрузчиках в разделе [Фреймворк — Загрузчики](../framework/bootloaders.md).
:::

protected const LOAD = [
    // ...

];

## Использование

По умолчанию компонент переводчика автоматически загружает все файлы локализации, расположенные в директориях `app/locale/{lang}`.

Чтобы получить список доступных локалей:

```php
namespace App\Endpoint\Web;

use Spiral\Translator\TranslatorInterface;

class HomeController
{
    public function index(TranslatorInterface $translator): void
    {
        dump($translator->getCatalogueManager()->getLocales());
    }
}
```

Чтобы изменить локаль, используйте метод `setLocale`.

> **Примечание**
> Рекомендуется использовать метод `setLocale` внутри посредника (middleware) или ядра домена, а затем правильно сбросить исходную локаль.

## Конфигурация

Фреймворк автоматически предоставляет конфигурацию по умолчанию внутри `Spiral\Bootloader\I18nBootloader`. Если вам нужны пользовательские настройки, вы можете определить их в `app/config/translator.php`:

### Файл конфигурации

Вот как может выглядеть типичная конфигурация:

```php app/config/translator.php
use Symfony\Component\Translation\Dumper;
use Symfony\Component\Translation\Loader;

return [
    'locale' => env('LOCALE', 'en'),
    'fallbackLocale' => env('LOCALE', 'en'),
    'directory' => directory('locale'),
    'autoRegister' => env('DEBUG', true),
    // доступные загрузчики локалей (ключ - расширение)
    'loaders' => [
        'php'  => Loader\PhpFileLoader::class,
        'po'   => Loader\PoFileLoader::class,
        'csv'  => Loader\CsvFileLoader::class,
        'json' => Loader\JsonFileLoader::class
    ],
    // методы экспорта
    'dumpers'  => [
        'php'  => Dumper\PhpFileDumper::class,
        'po'   => Dumper\PoFileDumper::class,
        'csv'  => Dumper\CsvFileDumper::class,
        'json' => Dumper\JsonFileDumper::class,
    ],
    'domains' => [
        // по умолчанию мы можем хранить все сообщения в одном домене
        'messages' => ['*']
    ]
];
```

**Ключевые моменты:**

1. **Настройки локали:** `locale` — это ваш основной язык, в то время как `fallbackLocale` — это язык по умолчанию, который приложение будет использовать, если указанный недоступен.
2. **Настройка директории:** Здесь находятся файлы языков. По умолчанию это директория `app/locale`.
3. **Загрузчики и дамперы:** Это классы, которые обрабатывают чтение из файлов переводов и запись в них.

### Изменение директории для файлов локализации

Если вы хотите использовать другую директорию для ваших языковых файлов, измените опцию `directory`:

```php app/config/translator.php
return [
    'directory' => directory('locale'),
];
```

Иногда вам могут понадобиться переводы из более чем одного местоположения. Например, когда вы используете внешние пакеты, которые приносят свои собственные переводы.

Чтобы указать несколько директорий, используйте `directories`:

```php app/config/translator.php
return [
    'directory' => directory('locale'),
    // ...
    'directories' => [
        directory('vendor/package/name/locale'),
        ...
    ],
    // ...
];
```

Вы также можете добавить новые директории, используя загрузчик (bootloader) `Spiral\Bootloader\I18nBootloader`:

```php
use Spiral\Boot\Bootloader\Bootloader;
use Spiral\Bootloader\I18nBootloader;

final class AppBootloader extends Bootloader
{
    public function init(I18nBootloader $i18n): void
    {
        $i18n->addDirectory('some/directory');
    }
}
```

> **Примечание**
> Если есть конфликт между файлами переводов, те, что находятся в основном приложении, будут иметь приоритет над дополнительными директориями.

## Импорт и экспорт

Возможно экспортировать пакеты локализации приложения в следующие форматы:

- PHP
- GetText PO
- CSV
- JSON

### Экспорт локали

Чтобы экспортировать пакеты локализации приложения, выполните:

```terminal
php app.php i18n:export en ./
```

> **Примечание**
> Экспортировать локаль `en` в текущую директорию.

Вы должны увидеть файл `messages.en.php`, созданный в этой директории. Чтобы экспортировать в альтернативных форматах:

```terminal
php app.php i18n:export en ./ -d po
```

Эта команда экспортирует локаль в формат `GetText`.

### Генерация локали

Фреймворк способен автоматически генерировать файлы локализации, используя статическую индексацию кода. Выполните команду `i18n:index`, чтобы найти все объявленные строки.

```terminal
php app.php i18n:index -vv
```

### Импорт локали

Импортируйте локаль в проект, поместив файлы в директорию `app/locale/{lang}`. Используйте форматы `GetText`, `PHP` или `JSON`.

## Локализация представлений

Spiral включает процесс представления, доступный для движков `Twig` и `Stempler`, для перевода исходного кода представлений. Переведенное представление будет сохранено в отдельном кэше представлений, и это предоставляет возможность переводить представления без каких-либо потерь производительности.

### Перевод представлений

Чтобы активировать перевод представлений, включите загрузчик (bootloader) `Spiral\Bootloader\Views\TranslatedCacheBootloader`. Убедитесь, что добавили этот загрузчик перед загрузчиками движков представлений:

:::: tabs

::: tab Использование метода

```php app/src/Application/Kernel.php
public function defineBootloaders(): array
{
    return [
         // ...
         \Spiral\Views\Bootloader\ViewsBootloader::class,
         \Spiral\Bootloader\Views\TranslatedCacheBootloader::class,
         // ...
    ];
}
```

Читайте больше о загрузчиках в разделе [Фреймворк — Загрузчики](../framework/bootloaders.md).
:::

::: tab Использование константы

```php app/src/Application/Kernel.php
protected const LOAD = [
    // ...
    \Spiral\Views\Bootloader\ViewsBootloader::class,
    \Spiral\Bootloader\Views\TranslatedCacheBootloader::class,
    // ...
];
```

Читайте больше о загрузчиках в разделе [Фреймворк — Загрузчики](../framework/bootloaders.md).

Оберните строку для перевода с помощью `[[ string ]]` в вашем шаблоне:

```html

```

> Измените локаль в вашем приложении, чтобы переключить перевод в представлении.

## Трейт Say

Возможно добавить способности перевода к любому объекту приложения, используя специализированный трейт `Spiral\Translator\Traits\TranslatorTrait`.

### Использование

Мы можем добавить трейт переводчика к контроллеру:

```php
namespace App\Endpoint\Web;

use Spiral\Translator\Traits\TranslatorTrait;

class HomeController
{
    use TranslatorTrait;

    public function index(): string
    {
        return $this->say('hello world!');
    }
}
```

> **Примечание**
> Выполните 'i18n:index' для индексации вызова строки.

### Сообщения класса

В случаях, когда сообщение определяется логикой и не может быть проиндексировано, используйте константы или свойства для объявления сообщений класса, каждая строка, обернутая в `[[]]`, будет автоматически проиндексирована.

```php
class HomeController 
{
    use TranslatorTrait;

    protected const MESSAGES = [
        'error'   => '[[An error]]',
        'success' => '[[Success]]'
    ];

    public function index(): string
    {
        echo $this->say(self::MESSAGES['error']);
    }
}
```
