# Продвинутые возможности — Планирование задач

Пакет [spiral-packages/scheduler](https://github.com/spiral-packages/scheduler) предоставляет простой API для выполнения задач по расписанию cron. Он может быть легко интегрирован в проект на основе Spiral.

## Установка

Для установки пакета вы можете использовать следующую команду:

```terminal
composer require spiral-packages/scheduler
```

После установки пакета вам необходимо добавить bootloader из пакета в ваше приложение:

:::: tabs

::: tab Использование метода

```php app/src/Application/Kernel.php
public function defineBootloaders(): array
{
    return [
        // ...
        \Spiral\Scheduler\Bootloader\SchedulerBootloader::class,
        // ...
    ];
}
```

Подробнее о bootloaders читайте в разделе [Framework — Bootloaders](../framework/bootloaders.md).
:::

::: tab Использование константы

```php app/src/Application/Kernel.php
protected const LOAD = [
    // ...
    \Spiral\Scheduler\Bootloader\SchedulerBootloader::class,
    // ...
];
```

Подробнее о bootloaders читайте в разделе [Framework — Bootloaders](../framework/bootloaders.md).
:::

Для запуска планировщика у вас есть два варианта:

1. Добавить запись конфигурации cron на ваш сервер, которая запускает команду `schedule:run` каждую минуту.

```bash
* * * * * cd /path-to-your-project && php app.php schedule:run >> /dev/null 2>&1
```

2. Запустить планировщик через RoadRunner, используя команду `schedule:work`. Эта команда будет работать на переднем плане и вызывать планировщик каждую минуту, пока вы не завершите команду:

```terminal
php app.php schedule:work
```

Вы можете использовать любой супервизор для поддержания процесса в фоновом режиме, например supervisord.

## Использование

Для использования пакета Scheduler в вашем проекте вы можете создать новый bootloader `SchedulerBootloader`.

> **Предупреждение**
> Не забудьте зарегистрировать `SchedulerBootloader` в вашем приложении!

Этот bootloader будет отвечать за управление задачами cron:

```php app/src/Application/Bootloader/SchedulerBootloader.php
use Spiral\Boot\Bootloader\Bootloader;
use Spiral\Scheduler\Schedule;
use Psr\Log\LoggerInterface;
use Spiral\Boot\DirectoriesInterface;

final class SchedulerBootloader extends Bootloader
{
    public function boot(Schedule $schedule, DirectoriesInterface $dirs): void
    {
        // Запуск консольной команды по имени
        $schedule->command('ping', ['https://google.com'])
            ->everyFiveMinutes()
            ->withoutOverlapping()
            ->appendOutputTo($dirs->get('runtime').'logs/cron.log');
            
        // Запуск консольной команды по имени класса
        $schedule->command(PingCommand::class, ['https://google.com'])
            ->everyFiveMinutes()
            ->withoutOverlapping()
            ->appendOutputTo($dirs->get('runtime').'logs/cron.log');
            
        // Запуск вызываемой задачи
        $schedule->call('Ping url', static function (LoggerInterface $logger, string $url) {
            $headers = @get_headers($url);
            $status = $headers && \strpos($headers[0], '200');

            $logger->info(\sprintf('URL: %s %s', $url, $status ? 'Exists' : 'Does not exist'));

            return $status;
        }, ['url' => 'https://google.com'])
           ->everyFiveMinutes()
           ->withoutOverlapping();
    }
}
```

Этот пример демонстрирует, как использовать пакет Scheduler для планирования различных типов команд для запуска с определенными интервалами и как настроить расписание для предотвращения пересечения и ведения журнала вывода.

Теперь вы можете проверить, что задачи cron зарегистрированы:

```terminal
php app.php schedule:list
```

```output
+--------------------------------------------------------+-------------+-------------+----------------------------+
|[32m Command                                                [39m|[32m Interval    [39m|[32m Description [39m|[32m Next Due                   [39m|
+--------------------------------------------------------+-------------+-------------+----------------------------+
| /usr/bin/php8.1 app.php ping 'https://google.com'      | */5 * * * * |             | 2023-01-12 12:55:00 +00:00 |
| /usr/bin/php8.1 app.php ping:site 'https://google.com' | */5 * * * * | Ping site   | 2023-01-12 12:55:00 +00:00 |
| callback: 'url'                                        | */5 * * * * | Ping url    | 2023-01-12 12:55:00 +00:00 |
+--------------------------------------------------------+-------------+-------------+----------------------------+
```

### Обратные вызовы

Вы можете использовать методы `before`, `then`, `when` и `skip` для регистрации обратных вызовов.

#### Обратный вызов Before

Метод `before` может использоваться для регистрации обратного вызова, который будет вызван перед выполнением запланированной задачи. Этот обратный вызов может использоваться для выполнения любой необходимой подготовки или настройки перед запуском задачи.

```php
$schedule->command('backup:run')
   ->everyFiveMinutes()
   ->before(static fn(Notifier $notifier) => $notifier->send('Starting backup...'));
   -> ...;
```

#### Обратный вызов Then

Метод `then` может использоваться для регистрации обратного вызова, который будет вызван после выполнения запланированной задачи. Этот обратный вызов может использоваться для выполнения любой необходимой очистки или дополнительной обработки после выполнения задачи.

```php
$schedule->command('backup:run')
   ->everyFiveMinutes()
   ->then(static fn(Notifier $notifier) => $notifier->send('Backup completed'));
   -> ...;
```

#### Обратный вызов When

Метод `when` может использоваться для регистрации обратного вызова, который будет вызван для определения того, должна ли запланированная задача быть выполнена или нет. Этот обратный вызов может использоваться для проверки любых ограничивающих условий, которые могут помешать выполнению задачи. Если обратный вызов when возвращает `false`, запланированная задача не будет выполнена.

```php
$schedule->command('email:digest')
   ->everyFiveMinutes()
   ->when(static fn(HolidaysCalendar $calendar) => !$calendar->isHoliday());
   -> ...;
```

#### Обратный вызов Skip

Метод `skip` может использоваться для регистрации обратного вызова, который будет вызван для определения того, должна ли запланированная задача быть пропущена или нет. Этот обратный вызов может использоваться для проверки любых условий, которые могут помешать выполнению задачи. Если обратный вызов skip возвращает `true`, запланированная задача не будет выполнена.

```php
$schedule->command('email:digest')
   ->everyFiveMinutes()
   ->skip(static fn(HolidaysCalendar $calendar) => $calendar->isHoliday());
   -> ...;
```

### Фоновые задачи

Вы можете запустить задачу в фоновом режиме, используя метод `runInBackground()`:

```php
$schedule->command('ping', ['https://google.com'])
   ->everyFiveMinutes()
   ->runInBackground()
   -> ...;
```

> **Предупреждение**
> Не запускайте вызываемые задачи в фоновом режиме. Это приведет к ошибке.

### Предотвращение пересечения задач

Когда используется метод `withoutOverlapping()`, пакет будет проверять, запущена ли уже команда или функция, перед планированием нового экземпляра. Если экземпляр команды или функции уже запущен, новый экземпляр не будет запланирован и будет пропущен. Это помогает предотвратить запуск нескольких экземпляров одной и той же команды или функции одновременно и потенциально вызывающих проблемы.

```php
$schedule->command('ping', ['https://google.com'])
   ->everyMinute()
   ->withoutOverlapping()
   -> ...;
```

В дополнение к поведению метода по умолчанию, вы также можете указать пользовательское время истечения блокировки в минутах. Это можно сделать, передав целочисленное значение в качестве аргумента методу.

```php
$schedule->command('ping', ['https://google.com'])
   ->everyMinute()
   ->withoutOverlapping(60)
   -> ...;
```

> **Примечание**
> По умолчанию время истечения блокировки составляет 24 часа.

### Выражения Cron

Вы можете использовать аргумент expression для назначения пользовательского выражения cron задаче.

Например, следующий код назначает выражение cron `* * * * *` (которое соответствует запуску каждую минуту) команде email:send:

```php
$schedule->command('email:send', expression: new \Cron\CronExpression('* * * * *'));
```

Кроме того, вы можете использовать вспомогательные методы для определения вашего расписания более понятным способом. Эти методы включают:

#### Минуты

| Метод                   | Описание                                     |
|-------------------------|----------------------------------------------|
| `everyMinute()`         | Каждую минуту: `* * * * *`                   |
| `everyEvenMinute()`     | Каждую четную минуту: `*/2 * * * *`          |
| `everyFiveMinutes()`    | Каждые пять минут: `*/5 * * * *`             |
| `everyTenMinutes()`     | Каждые десять минут: `*/10 * * * *`          |
| `everyFifteenMinutes()` | Каждые пятнадцать минут: `*/15 * * * *`      |
| `everyThirtyMinutes()`  | Каждые тридцать минут: `0,30 * * * *`        |

> **Примечание**
> Больше примеров того, как запланировать задачу для запуска в определенные минуты, вы можете найти [здесь](https://github.com/butschster/CronExpressionGenerator#manipulate-hours).

#### Часы

| Метод                  | Описание                                                     |
|------------------------|--------------------------------------------------------------|
| `hourly()`             | Каждый час в 00 минут: `0 * * * *`                          |
| `hourlyAt(15)`         | Каждый час в указанную минуту: `15 * * * *`                 |
| `hourlyAt(15, 30, 45)` | Каждый час в 15, 30, 45 минут: `15,30,45 * * * *`          |
| `everyTwoHours()`      | Каждый день в 00:00: `0 0 * * *`                            |

> **Примечание**
> Больше примеров того, как запланировать задачу для запуска на почасовой основе, вы можете найти [здесь](https://github.com/butschster/CronExpressionGenerator#manipulate-hours).

#### Дни

| Метод                        | Описание                                                           |
|------------------------------|--------------------------------------------------------------------|
| `daily()`                    | Каждый день в 00:00: `0 0 * * *`                                  |
| `daily(13)`                  | Каждый день в указанное время: `0 13 * * *`                       |
| `daily(3, 15, 23)`           | Каждый день в 03:00, 15:00, 23:00: `0 3,15,23 * * *`             |
| `twiceDaily(1, 13)`          | Каждый день в 01:00, 13:00: `0 1,13 * * *`                       |
| `lastDayOfMonth()`           | Каждый месяц в последний день в 00:00: `0 0 L * *`               |
| `lastDayOfMonth(12)`         | Каждый месяц в последний день в 12:00: `0 12 L * *`              |
| `lastDayOfMonth(12, 30)`     | Каждый месяц в последний день в 12:30: `30 12 L * *`             |
| `lastWeekdayOfMonth()`       | Каждый месяц в последний рабочий день в 00:00: `0 0 LW * *`      |
| `lastWeekdayOfMonth(12)`     | Каждый месяц в последний рабочий день в 12:00: `0 12 LW * *`     |
| `lastWeekdayOfMonth(12, 30)` | Каждый месяц в последний рабочий день в 12:30: `30 12 LW * *`    |

> **Примечание**
> Больше примеров того, как запланировать задачу для запуска на ежедневной основе, вы можете найти [здесь](https://github.com/butschster/CronExpressionGenerator#manipulate-days).

#### Дни недели

| Метод      | Описание                               |
|------------|----------------------------------------|
| `weekly()` | Каждую неделю в понедельник: `0 0 * * 0` |

> **Примечание**
> Больше примеров того, как запланировать задачу для запуска на еженедельной основе, вы можете найти [здесь](https://github.com/butschster/CronExpressionGenerator#manipulate-days-of-week).

### Месяцы

| Метод                   | Описание                                                       |
|-------------------------|----------------------------------------------------------------|
| `monthly()`             | Каждый месяц 1-го числа в 00:00: `0 0 1 * *`                 |
| `monthly(12)`           | Каждый месяц 1-го числа в 12:00: `0 12 1 * *`                |
| `monthly(12, 30)`       | Каждый месяц 1-го числа в 12:30: `30 12 1 * *`               |
| `monthlyOn(15, 12)`     | Каждый месяц 15-го числа в 12:00: `0 12 15 * *`              |
| `monthlyOn(15, 12, 30)` | Каждый месяц 15-го числа в 12:30: `30 12 15 * *`             |
| `quarterly()`           | Каждый квартал yyyy-01,03,06,09-01 00:00: `0 0 1 1-12/3 *`    |
| `yearly()`              | Каждый год yyyy-01-01 00:00: `0 0 1 1 *`                     |

> **Примечание**
> Больше примеров того, как запланировать задачу для запуска на ежемесячной основе, вы можете найти [здесь](https://github.com/butschster/CronExpressionGenerator#manipulate-months).

## Консольные команды

#### Просмотр запланированных задач

Используйте команду `schedule:list` для просмотра всех запланированных задач:

```terminal
php app.php schedule:list
```

#### Запуск планировщика

Используйте команду `schedule:work` для запуска планировщика:

```terminal
php app.php schedule:work
```
