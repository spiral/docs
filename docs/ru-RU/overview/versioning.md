# Обзор — Версионирование

Все компоненты Spiral следуют https://semver.org/ с разрешенной обратной совместимостью для релизов безопасности.

## Текущая версия

Текущая версия фреймворка — `3.*`. Предыдущие релизы можно найти [здесь](https://github.com/spiral/framework/releases)

| Версия     | PHP   | Дата релиза | Окончание разработки функций |
|------------|-------|-------------|------------------------------|
| 0.*        | ≥ 5.0 | Nov 2013    | Dec 2017                     |
| 1.*        | ≥ 7.2 | Apr 2017    | Dec 2019                     |
| 2.*        | ≥ 7.4 | May 2019    | Dec 2022                     |
| <b>3.*</b> | ≥ 8.1 | Sep 2022    | -                            |
