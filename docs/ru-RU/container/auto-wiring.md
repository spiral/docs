# Контейнер — Автосвязывание

Spiral пытается скрыть реализацию и конфигурацию контейнера от вашего домена, предоставляя богатую функциональность автосвязывания. Хотя правила автосвязывания просты, важно их изучить, чтобы избежать неправильного поведения фреймворка.

Класс `Spiral\Core\Container\Autowire` позволяет делегировать опции контейнеру и передавать определенные значения конфигурации вашим классам без жесткого кодирования. Это может быть полезно для отделения конфигурации от кода и для упрощения изменения поведения приложения без изменения самого кода.

```php app/config/session.php
use Spiral\Core\Container\Autowire;
use Spiral\Session\Handler\FileHandler;

return [
    // ...
    'handler' => new Autowire(
        FileHandler::class,
        [
            'directory' => directory('runtime') . 'session',
            'lifetime' => (int)env('SESSION_LIFETIME', 86400),
        ]
    ),
];
```

Когда контейнер пытается разрешить `Autowire`, он автоматически создаст экземпляр класса `FileHandler` и передаст опции `directory` и `lifetime` в конструктор.

Это позволяет легко настраивать ваши классы и передавать определенные опции без необходимости жестко кодировать их в вашем коде, и может быть особенно полезно для настройки классов, которые имеют много опций или используются в нескольких частях вашего кода.
